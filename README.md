# Projetos de Desenvolvimento Web

Este repositório reúne dois projetos desenvolvidos na disciplina de Programação para a Web, com o objetivo de aplicar conceitos de HTML, CSS e JavaScript na criação de páginas web.

Os projetos possuem propostas diferentes: o primeiro foi desenvolvido a partir do código e das requisições apresentadas na atividade, enquanto o segundo utiliza o framework **W3.CSS** para auxiliar na estruturação e estilização da página.

Cada projeto está organizado em uma **branch diferente** do repositório.

---

## 📌 Projeto 1 — Página Web

**Branch:** `main`

O primeiro projeto consiste no desenvolvimento de uma página web seguindo as requisições e orientações propostas na atividade.

A página foi construída utilizando os conhecimentos de desenvolvimento web, com a organização dos arquivos em HTML, CSS e JavaScript.

### Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

### Características

- Estruturação da página utilizando HTML;
- Estilização e organização visual com CSS;
- Utilização de JavaScript para funcionalidades e interações;
- Organização dos arquivos em pastas;
- Desenvolvimento seguindo as especificações e requisitos apresentados na atividade.

---

## 🎨 Projeto 2 — Página Web com W3.CSS

**Branch:** `master`

O segundo projeto consiste na criação de uma página web utilizando o **W3.CSS**, um framework de CSS que disponibiliza classes prontas para facilitar a construção e estilização de páginas.

Nesse projeto, foram aplicados os recursos oferecidos pelo W3.CSS para criar uma página organizada, responsiva e visualmente estruturada.

### Tecnologias utilizadas

- HTML5
- CSS3
- W3.CSS
- JavaScript

### Características

- Utilização do framework W3.CSS;
- Layout responsivo;
- Uso de classes do W3.CSS para estilização;
- Organização de conteúdos em seções;
- Utilização de componentes e estilos disponibilizados pelo framework;
- Aplicação de JavaScript para funcionalidades da página.

---

## 🌿 Branches do Repositório

Os dois projetos estão separados em branches diferentes:

| Branch | Projeto | Descrição |
|---|---|---|
| `main` | Projeto 1 | Página desenvolvida seguindo as requisições e orientações da atividade |
| `master` | Projeto 2 | Página desenvolvida utilizando o framework W3.CSS |

Para visualizar cada projeto, basta selecionar a respectiva branch no GitHub.

---

## 🎯 Objetivo

Os projetos têm como objetivo colocar em prática conceitos fundamentais de desenvolvimento web, trabalhando com a criação, estruturação e estilização de páginas, além da utilização de JavaScript para adicionar interatividade.

A separação dos projetos em branches permite manter as duas versões organizadas dentro do mesmo repositório, possibilitando visualizar e comparar as diferentes abordagens utilizadas no desenvolvimento.
